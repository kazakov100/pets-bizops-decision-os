Braun and Clarke's six-phase thematic analysis method is the standard
academic approach for turning unstructured qualitative feedback (reviews,
complaint text, open-ended survey answers) into reliable named themes
rather than impressionistic summaries. The six phases: (1) familiarize
yourself with the full dataset before coding anything, (2) generate initial
codes -- short labels applied consistently across the data, (3) search for
candidate themes by grouping related codes, (4) review themes against the
full dataset to check they actually hold up and aren't just one or two loud
examples, (5) clearly define and name each theme so it has one core
meaning, not several blended ideas, (6) produce the write-up connecting
each theme back to specific supporting examples. The discipline this
imposes when reading a small set of public complaint themes: a theme is
only as credible as its review (step 4) -- if a "theme" is really just one
vivid complaint generalized into a pattern, it should be labeled as an
isolated anecdote, not presented with the same confidence as a theme that
recurs across many independent reviews. The process is explicitly iterative,
not a one-pass classification -- themes should be revisited as more
evidence comes in.

Source: Braun, V. & Clarke, V., reflexive thematic analysis six-phase framework (Qualitative Research in Psychology, 2006; subsequent methodology papers) -- https://www.thedegreedoctor.com/blog/braun-and-clarke-thematic-analysis-how-to-do-the-six-step-process-in-your-qualitative-research-project
